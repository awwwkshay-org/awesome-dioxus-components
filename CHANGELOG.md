# Changelog

All notable changes to `adico` are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project
uses [Semantic Versioning](https://semver.org/) once `0.1.0` ships.

Each publishable crate (`adico-cli`, `adico-primitives`, `adico-registry-core`)
and the registry itself version together for now; this will split into
per-crate changelogs if their release cadences diverge.

## [Unreleased]

## [0.1.0] - 2026-09-23

### Added

- 69 registry components and 67 headless primitives across the `@adico`
  official registry.
- `adico init`/`add`/`list`/`view`/`css build`/`css check` CLI commands.
- Static-HTTPS and local organization-registry support, alongside the
  embedded official registry.

### Changed

- Relicensed to dual `MIT OR Apache-2.0`.
